## Architecture Notes

### Authorization Flow

1. **Token Storage:** Zustand persist stores JWT token in localStorage under `auth-storage`
2. **Token Retrieval:** `api/client.ts` reads token from localStorage and adds `Authorization: Bearer {token}` header
3. **Backend Verification:** `ProjectController` uses `[Authorize]` attribute and `ICurrentUserService` to verify JWT
4. **User Isolation:** `ProjectService.GetUserProjectsAsync()` filters by `userId` automatically

### Data Flow

```
LibraryPage.tsx
  ├─> useAuthStore() → user.username
  ├─> useQuery(['novelLibrary']) → getNovelLibrary() → books (legacy, for compatibility)
  └─> useQuery(['userStats']) → projectService.getUserStats()
        └─> api('/project?pageNumber=1&pageSize=1000')
              └─> Authorization: Bearer {token} (auto-added)
                    └─> Backend: ProjectController.GetProjects()
                          └─> IProjectService.GetUserProjectsAsync(userId)
                                └─> Returns: PagedResponse<ProjectResponse>
```

### Storage Usage Calculation

Current implementation uses a rough estimate:
- Formula: `(totalWordCount / 1000) * 2KB / 1024 = storageUsedMb`
- Assumption: ~2KB per 1000 words (includes JSON overhead)
- Future enhancement: Backend could provide actual filesystem size
