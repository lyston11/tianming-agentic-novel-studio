不可混合的输入来源

候选正史分支本批次前序候选章、候选事实与版本依赖
章节任务合同本章目标、必须发生、禁止发生、情绪与节奏、结束状态
用户全局知识库自动归纳分类后的资料、写法、风格、灵感与事实参考
→
Context Compiler
检索计划分别查询设定、人物、连续性、叙事承诺、知识素材、文风示例
混合召回结构化查询 + 向量召回 + 关键词/实体 + 依赖图 + 邻近章节
重排与冲突裁剪任务相关性、权威级别、时效、来源质量、重复和冲突
Chapter Context Contract硬事实、软素材、必须承接、禁止项、知识引用、来源证据、预算
天命写作模型只在合同允许的创作空间中生成正文与结构化状态变化
→
独立验证
协议校验正文完整、状态变化可解析、版本与来源齐全
正史校验人物、时间线、世界规则、前章承接、候选分支一致性
任务校验章节目标、剧情承诺、伏笔、节奏和结束状态是否完成
知识校验必须参考是否使用、硬边界是否违反、引用是否可追溯
独立审稿人物动机、叙事逻辑、文风、可读性、重复、审美质量
失败项 → 结构化修订合同 → 局部改写 → 只重验受影响维度　达到预算仍失败时才产生 NeedsDecision
RAG 不裁决事实召回结果与正史冲突时，正史优先；知识只作为素材或冲突证据
模型不自证正确写作模型与审稿模型职责分离，确定性门禁验证关键协议和硬约束
通过也不直接入正史产出候选正文、候选事实和知识使用记录，批次验收后才晋升
