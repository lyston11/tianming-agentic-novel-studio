知识库在新 Agent 中的位置

知识资产提供证据和创作约束，但不能成为记忆副本，也不能直接成为正史

知识资产层
个人知识库跨项目可复用的写作方法、资料、题材知识
项目知识库本书研究材料、参考作品分析、术语与设定素材
外部研究快照文件、网页、检索结果；保留来源、版本与引用证据
→
知识内核
摄取与结构化解析、切块、去重、分类、来源追踪
项目绑定与约束参考 / 灵感 / 软约束 / 硬约束 / 禁止使用
冲突与适用性分析检查资料之间、资料与正史之间的冲突
Knowledge Pack 编译按领域任务生成小而精确、带证据的知识包
→
消费与晋升
设定 / 规划 / 写作 / 审稿内核只读取当前任务的 Knowledge Pack，不直接搜索整个库
候选正史分支知识被采用后产生“候选事实”，记录来源与采用理由
正式作品状态只有批次验收后，候选事实才晋升为正史
知识库 ≠ 记忆知识资产有来源、版本、适用范围；记忆只保存偏好和经验
检索 ≠ 决策Qdrant 找候选证据，知识内核负责筛选、冲突和任务打包
引用 ≠ 正史任何资料都必须经过领域内核采用和用户验收才能进入作品事实
