数据库架构设计

多用户系统的核心数据模型

📦 数据库选择

SQLite（推荐MVP）
✓ 无需安装数据库服务
✓ 单文件部署简单
✓ 适合中小规模（<10K用户）
✗ 并发写入有限制
PostgreSQL（长期）
✓ 生产级性能
✓ 支持高并发
✓ 丰富的生态
✗ 需要额外维护数据库服务

🗂️ 核心数据表设计

-- 用户表（核心）
CREATE TABLE
users (
id TEXT PRIMARY KEY, -- UUID
username TEXT UNIQUE NOT NULL,
email TEXT UNIQUE NOT NULL,
password_hash TEXT NOT NULL,
role TEXT NOT NULL, -- 'admin' | 'author'
created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
last_login_at DATETIME,
is_active BOOLEAN DEFAULT 1
);
-- 用户设置表（1对1）
CREATE TABLE
user_settings (
user_id TEXT PRIMARY KEY,
llm_provider TEXT,
llm_api_key_encrypted TEXT, -- 加密存储
llm_base_url TEXT,
llm_model TEXT,
llm_temperature REAL DEFAULT 0.7,
llm_max_tokens INTEGER DEFAULT 4096,
-- Embedding配置
embedding_provider TEXT DEFAULT 'local',
embedding_model TEXT,
-- Agent配置
agent_default_risk TEXT DEFAULT 'Medium',
agent_auto_continue BOOLEAN DEFAULT 1,
agent_max_auto_steps INTEGER DEFAULT 12,
-- 创作默认值
default_genre TEXT DEFAULT '玄幻',
default_chapter_word_count INTEGER DEFAULT 3000,
-- 界面偏好
theme TEXT DEFAULT 'dark',
language TEXT DEFAULT 'zh-CN',
FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
-- 小说项目表
CREATE TABLE
novel_projects (
id TEXT PRIMARY KEY,
user_id TEXT NOT NULL,
title TEXT NOT NULL,
genre TEXT,
core_hook TEXT,
created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
-- 记忆数据表（JSON存储）
CREATE TABLE
memories (
id TEXT PRIMARY KEY,
user_id TEXT NOT NULL,
project_id TEXT, -- NULL表示全局记忆
memory_type TEXT NOT NULL, -- 'author' | 'project' | 'execution'
content TEXT NOT NULL, -- JSON格式
updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

🔐 关键设计决策

✓ 采用方案
• API Key 加密存储（AES-256）
• 密码使用 BCrypt hash
• 用户ID使用 UUID
• 记忆数据存 JSON字段（保持灵活性）
✗ 不采用方案
• ❌ 明文存储API Key
• ❌ 自增ID（不利于分布式）
• ❌ 记忆数据拆分多表（过度设计）
• ❌ 文件路径存数据库（维护困难）

建议：先用 SQLite 快速验证，数据库文件放在 App_Data/Database/novelagent.db。未来用户量增长时，可以无缝迁移到 PostgreSQL（.NET 的 EF Core 支持两者）。
